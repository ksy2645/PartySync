# PartySync

Discord 모임의 가능 시간을 모아 함께할 일정을 정하는 서비스입니다.

## 서비스 이용

https://partysync.duckdns.org

- Discord 로그인 후 가능 시간 입력
- 조건에 맞는 일정 추천 및 확정
- Discord 일정 안내·리마인더·반복 일정 지원
